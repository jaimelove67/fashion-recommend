# 知己 · 跨站试穿

此扩展将选图、实时试穿与收藏整合到一个独立窗口，支持置顶显示，并将喜欢的商品图片和链接保存回知己项目账号。

## 安装

源码目录需要先在项目根目录运行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File tools/package-try-on-extension.ps1
```

打开 `chrome://extensions` 或 `edge://extensions`，开启开发者模式，用“加载已解压的扩展程序”选择 `output/zhiji-try-on-extension`。也可从项目趋势页下载 ZIP，解压并加载含有 `manifest.json` 的目录。共用的 `images.js` 和 `liveTryOn.js` 由打包步骤复制，不能直接加载本源码目录。

## 使用

1. 登录项目，在浏览器工具栏打开“知己跨站试穿”，点击“连接此项目网站”，批准项目站点权限。
2. 在项目趋势页点击“开启跨站试穿”，保留这个项目标签页。
3. 打开 HTTPS 购物网站，点击扩展图标，在该网站启用浮窗并授权。
4. 拖入商品图片，确认名称和类别，点击同意开始。图片 CDN 若在另一个域名，需单独授权读取该图片站点。
5. 首次开始时批准 Anywear 站点权限。打开合一试穿窗口后，购物网页的初始浮窗会收起；在同一个窗口中允许摄像头、查看画面并点击“喜欢，保存到项目”。通过“查看我的喜欢穿搭”返回项目。
6. 在窗口顶部点击“置顶显示”，选图、画面和收藏会一起置顶。随后可以打开其他网页，并把商品图片拖入置顶窗口的选图区域，也可以选择或拖入本地图片。读取新图片域名时仍会询问权限。

合一窗口打开后，切换网页、购物页面换页或关闭源购物标签页都不会关闭它；超时或服务结束会移除试穿画面，保留选图和收藏面板。关闭整个试穿窗口会恢复已授权购物网页的初始浮窗；停止跨站试穿、关闭已连接项目标签页或账号重连会清理对应窗口。浏览器重启后重新连接项目。

置顶使用浏览器的 Document Picture-in-Picture，必须由用户点击开启，并要求保留原试穿窗口；关闭置顶视图会回到普通窗口，关闭原试穿窗口会同时关闭置顶视图。切换置顶与普通模式时浏览器可能重载控件并重新连接试穿服务，额度以服务方计算为准。浏览器不支持该接口时仍可使用普通合一窗口。跨窗口拖图若没有携带原商品链接，收藏的来源链接会留空；需要保留链接时，可以先在授权购物页拖入商品，再使用本地图片。

## “anywear.decart.ai 拒绝连接”

2026-10-14 核验发现，试衣控件响应带有 `Content-Security-Policy: frame-ancestors 'self'`，浏览器禁止它嵌入购物网站或扩展来源。0.1.1 改为独立试穿窗口；0.1.2 进一步将扩展操作面板与同源试衣控件作为同一窗口内的两个并列 frame，选图、试穿、收藏都在一起完成。无需关闭浏览器安全设置。

更新时重新打包，或重新下载并解压 ZIP，在扩展管理页点击重新加载，再刷新项目及购物网页。首次试穿需批准 Anywear 的可选站点权限。商品图片通过扩展脚本传入，不写入试穿窗口地址，也不保存到扩展存储。

开始后，商品图片和摄像头画面会发送给 Anywear / Decart。生成效果、额度、计费和数据处理由服务方提供，试穿仅供款式与配色参考。收藏保存原商品图片和链接，不保存摄像头视频。扩展不默认访问所有网站，也不复制项目的登录 Cookie 或密钥。

完整说明见项目 `docs/anywear-live-try-on.md`。
