# 知己 · 跨站试穿

此扩展在用户授权的购物网页显示试穿浮窗，将喜欢的商品图片和链接保存回知己项目账号。

## 安装

源码目录需要先在项目根目录运行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File tools/package-try-on-extension.ps1
```

打开 `chrome://extensions` 或 `edge://extensions`，开启开发者模式，用“加载已解压的扩展程序”选择 `output/zhiji-try-on-extension`。也可从项目趋势页下载 ZIP，解压并加载含有 `manifest.json` 的目录。共用的 `images.js` 和 `liveTryOn.js` 由打包步骤复制，不能直接加载本源码目录。

## 使用

1. 登录项目，在浏览器工具栏打开“知己跨站试穿”，点击“连接此项目网站”，批准项目站点权限。
2. 在项目趋势页点击“开启跨站试穿”，保留这个项目标签页。
3. 打开 HTTPS 购物网站，点击扩展图标，在该网站启用浮窗并授权。
4. 拖入商品图片，确认名称和类别，点击同意开始。图片 CDN 若在另一个域名，需单独授权读取该图片站点。
5. 允许摄像头，试穿满意后点击“喜欢，保存到项目”。通过“查看我的喜欢穿搭”返回项目。

可拖动浮窗位置、收起或关闭。收起会停止试穿；关闭跨站试穿或关闭连接的项目标签页会关闭所有连接浮窗。浏览器重启后重新连接项目。图片无法直接读取时，可以先拖入商品再选择下载的本地图片，以保留原商品链接。

开始后，商品图片和摄像头画面会发送给 Anywear / Decart。生成效果、额度、计费和数据处理由服务方提供，试穿仅供款式与配色参考。收藏保存原商品图片和链接，不保存摄像头视频。扩展不默认访问所有网站，也不复制项目的登录 Cookie 或密钥。

完整说明见项目 `docs/anywear-live-try-on.md`。
