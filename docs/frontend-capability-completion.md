# 前端能力补齐记录

日期：2026-11-03。基于当前工作区，沿用既有后端接口与权限控制。

## 页面入口

| 入口 | 新增能力 |
| --- | --- |
| 管理后台 → 穿搭技巧管理 | 读取整理状态、最近尝试/成功、下次计划、近七天尝试次数；手动整理；补全对照图；显示月度已预留额度与余额。 |
| 管理后台 → 操作日志 | 补全趋势复核、趋势刷新、技巧整理、对照图操作及已尝试、已跳过、已排队结果筛选。 |
| 管理后台 → 运营总览 | 展示衣橱单品总数和用户反馈总数。 |
| 个人形象档案 → 形象分析 | 11 个分析字段均可编辑，显示风格拓展建议；编辑普通建议时保留摘要。观察特征改变时使旧建议失效，可手动补回。 |
| 知己 AI 助手 → 衣橱搭配 → 选择本次衣物 | 首次生成前指定最多 4 件或排除最多 100 件衣物；仅显示已确认衣物；提交前检查冲突和失效选择。 |
| 穿搭鉴赏 → 高级筛选 | 默认折叠，默认仍为近 24 小时；可选择近 7 天、平台及标题/标签关键词。筛选失败保留并标明上次成功内容；周结果超出画廊十图容量时可从补充列表逐条查看。 |
| 穿搭鉴赏 → 收藏款式参考 | 对内容明确提及的款式收藏本站单品示意图，保留原帖来源；不会把原帖整套图当单品，也不会加入个人衣橱。支持抖音、微博、小红书。 |

新增界面不堆叠常驻功能说明。只保留操作状态、错误、来源与费用信息，字段约束在编辑时显示。

## 行为边界

- 管理页进入及刷新仅执行 GET。手动整理和补图由明确按钮触发，不自动调用付费模型；继续遵守后端配额，排队成功不等同配图成功。
- 状态读取和提交继续使用现有会话、CSRF 与管理员权限；会话变更后的旧响应不得恢复私人状态。
- 站内收藏只读取 `/assets/trend-pieces/` 下的已知格式图片；读图后再次检查会话，禁止将外部或私人图片地址作为该入口的自动读取目标。
- 原有独立问答、完整衣橱搭配校验、购物扩展收藏与默认每日精选流程保留。
- 本轮没有更改后端、数据库迁移、部署配置或线上数据。

- 浏览器管理/个人分析/助手/推荐组：`admin-techniques.spec.js`、`personal-profile-analysis.spec.js`、`global-assistant.spec.js`、`product-improvements.spec.js`、`recommendation-context.spec.js`。
- 浏览器鉴赏组：`trend-filter-favorites.spec.js`、`trend-demo-and-sources.spec.js`、`trend-daily-selection.spec.js`、`trend-empty-state.spec.js`、`weekly-techniques.spec.js`。

浏览器测试使用隔离接口响应和测试账号数据，检查真实 Vue 页面操作、请求参数、错误恢复与桌面/手机布局；不代表真实模型、付费生图或生产环境已完成验收。
