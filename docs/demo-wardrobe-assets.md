## 使用边界

- 这些图片用于本地毕设/演示环境，不代表产品已经获得商业图库授权。
- PNGimg 的图片应保留来源和许可记录；正式上线前需要逐张复核当前许可，并按需要替换为已取得授权的商品图。
- Commons 图片的许可可能逐文件不同，使用时按上表的文件页和许可执行。
- 这批素材特意排除了模特穿着整套服装的图片；个别商品摄影仍可能包含衣架、地面或透明人台，但画面主体只有单件衣物/鞋履/配饰。

## 每日推荐模特原型与运行时生图

- 后端资源 `backend/src/main/resources/reference_photo/model-male.png` 与 `model-female.png` 是从用户指定的两张原型图原样复制而来，分别对应 `docx/reference_photo/exec-0558d0a4-c680-497c-a315-ddecd63ad798.png` 与 `docx/reference_photo/exec-c2af0af1-828a-46c8-98fc-e8294ddfb2dc.png`。
- 推荐页按参考效果把当前搭配拆成中央模特和四角单品卡；单品卡始终重新关联当前衣橱，不使用外部商品图替代。前端调用 `/api/v1/me/recommendations/{id}/visual` 后，后端使用 `wan2.6-image` 异步生成当日模特穿搭图。
- 上传到 MinIO 的衣物会在服务端读取后以 Base64 作为图像参考；仅有相对演示资源 URL 的种子数据需要设置 `BAILIAN_IMAGE_REFERENCE_BASE_URL` 才能把衣物图一并送给阿里云。即使没有可传入的衣物图，提示词仍只列出已确认的当前衣橱单品，且前端不会展示不属于衣橱的单品卡。
- 生成提示词核心约束：保留档案指定性别与原型人物特征；只使用当前推荐中已确认的衣橱单品；全身棚拍；不添加其他服装、配饰、文字或水印。生图不可用时保留画板与衣橱单品，并标注未生成状态，不把原型图当作当日穿搭结果。
