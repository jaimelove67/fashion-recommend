# 注册图形验证码

注册需要填写账号、密码、确认密码和图片中的 5 位验证码。验证码不区分大小写，3 分钟内有效；点击图片可换一张。服务端验证通过后才创建账户，并沿用注册后自动登录的流程。

验证码由后端本地生成 PNG，不使用邮箱、Cloudflare 或其他第三方服务，不需要 API Key 或付费订阅。已有账户仍使用账号和密码登录。

## 接口与会话

- `GET /api/v1/auth/captcha`：允许匿名访问，返回 `data.image`（PNG Data URL）和 `data.expiresInSeconds`（180），响应设置 `Cache-Control: no-store`，同时建立浏览器会话。
- `POST /api/v1/auth/register`：提交 `username`、`password`、`captcha`，需要携带获取图片时的会话 Cookie 和现有 CSRF Token。没有验证码、验证码错误、过期、刷新后使用旧码或跨会话提交，均不能创建账户。
- 每张图片只有一次校验机会，输入错误也会消耗。注册请求失败后前端自动换图并清空输入，用户也可以手动刷新。
- 答案仅以摘要保存在服务端会话中，接口和日志不返回明文答案。并发提交也只能消费一次。

验证码使用现有服务端会话，不增加数据库表。Docker 运行镜像显式安装字体，以支持无桌面环境生成验证码图片。需要重新构建并重启后端、更新前端资源后生效。

## 验证范围

后端测试覆盖图片生成、有效期边界、大小写、刷新、一次性消费、跨会话隔离、并发提交以及 CSRF；浏览器模拟接口测试覆盖注册、验证码失败后换图、加载失败和原有登录。固定验证码仅存在于测试配置中，生产代码没有固定答案或校验开关。

调用真实服务的旧注册脚本也必须先取图、保持 Cookie 并填写图片答案；仅提交账号和密码会返回 400。涉及真实模型、个人资料和数据库写入的可选联调套件不在本次验证范围内。
