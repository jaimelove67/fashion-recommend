## 配置及运行边界

新项目只使用其本机原有配置中的 `DASHSCOPE_API_KEY`、`DASHSCOPE_BASE_URL`、`QWEN_MODEL`，没有复制穿搭项目的数据库、账号或对象存储配置。服务器配置文件是 `/opt/sincetic/shared/.env`，文件权限为 `600`，所在目录权限为 `700`。密钥不包含在运行镜像、公开静态文件或本说明中。

应用无数据库；会话和学习档案保存在访问者浏览器的 localStorage。换浏览器、换访问地址或清除站点数据后，不会自动同步这些学习记录。运行时使用仓库的 JSON 资料库，原始 PDF 不参与运行，因此未打入镜像。

应用内存上限为 512 MiB，CPU 上限为一个逻辑核，以非 root 用户、只读文件系统运行。问答和测评接口合计按每个来源 IP 每分钟 6 次限制，允许少量突发；每个 IP 最多 2 个同时请求，全站最多 4 个同时请求。超限返回 429，单次请求体超过 512 KiB 返回 413。模型调用仍使用配置账户的额度。

原前端额外连接 `sincetic-demo_default` 网络，新应用不加入穿搭项目数据库网络。原发布目录的 `docker-compose.cloud.yml` 已为前端声明这个外部网络，以便按该配置重建时恢复连接。不要在这项临时部署仍使用中时直接删除该网络。
