# 每日趋势穿搭精选

更新于2026-10-16。每日展示目标为跨平台合计5套：2套男装穿搭、2套女装穿搭、1套小众风格欣赏。男女装表示服装方向，不推断作者或穿着者的性别。

## 采集与筛选

- 沿用应用启动后采集一次、北京时间每天12:00定时采集的安排。微博、抖音、小红书默认分别搜索“男士穿搭”“女士穿搭”“小众风格穿搭”。每平台最多50条候选，三种查询交错合并后按稳定原帖ID去重；单次搜索失败保留该平台上次完整文件，并报告失败。
- 搜索词只用于发现内容。分类依据原帖文案和标签中的明确服装对象或具体风格，不用作者姓名、外貌、粉丝数或搜索词代替证据。两种服装对象同时出现、无性别穿搭及分类不明的候选，不强行计入男装或女装名额。
- 小众欣赏独立占1个名额。例如哥特风、洛丽塔、蒸汽朋克、赛博朋克、视觉系、暗黑先锋等具体服装风格；“低粉博主”“小众品牌”或单独的“小众”营销词不能证明服装风格。文字标签是可复核的初筛，不等于已理解图片。
- 后端先执行[内容与图片复核](trend-content-policy.md)、隐藏状态及内容版本检查，再限定原帖发布时间与采集时间都在最近24小时。旧帖有互动增长也不能补入当日名额。更新服装分类标签会使原复核状态失效，单纯更新互动数不会。
- 所有合格平台的候选都参与每日配额选择，保留原有来源与排名偏好。同一原帖ID、去除跟踪参数后的原帖链接，或同一展示图片不能重复占位；不同图片的身份查询参数会保留。已知微博图片域名和尺寸变体统一识别，不根据相同作者姓名或图集里的公共背景照合并不同穿搭。
- 同一套不能同时占男装/女装和小众欣赏名额。优先寻找可满足配额的组合，避免先选中的重复图片挡住可用替代项。数量不足时如实保留缺额，不复制、不修改日期、不放宽复核，也不用其他类别顶替。

既有来源评分和高粉/低粉博主的排序仍用于候选优先级。最终选5套后才执行来源或主题筛选，筛选结果是当天入选集合的子集。每个平台的采集数、合格候选数与最终入选数分别计算。

自动去重基于原帖与图片链接，不比较不同CDN重新上传或裁剪后的图片内容；这类重复需要在实际图片复核时确认。

## 页面与接口

公开趋势接口默认时间范围为 `day`，返回 `dailySelection`：`target`、三个实际分类数量、`missing`缺额及逐帖`assignments`。显式请求`week`保留既有七天行为，不附每日配额。

趋势页显示“每日精选 X / 5 套”和男装、女装、小众欣赏的实际数量；不足时列出缺少的类别。画廊图片、下方简析与深入分析显示所属名额，小众项同时展示文字分类依据。保持“选中画廊 → 简析 → 主动打开深入分析 → 衣橱应用”，尚未整理的帖子不虚构搭配理由。历史分析示例单独展示，不计入每日数量；此前删除的来源筛选与更新时间工具条不恢复。

## 运行边界

`TREND_REFRESH_CRON`默认`0 0 12 * * *`，时区为`Asia/Shanghai`。单平台多次查询的读取超时由`TREND_COLLECTION_READ_TIMEOUT`控制，默认`300s`，Compose与直接启动后端均支持。

匿名公开搜索可能遇到登录墙或验证页，新候选也需要图片复核，因此不能承诺每天一定有5套可公开内容。当前改动在本地实现和验证，没有部署新版本、操作社交账户或执行真实平台采集；模拟接口的浏览器检查不代表已抓取到当日5套。
