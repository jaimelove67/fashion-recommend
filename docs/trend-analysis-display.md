# 趋势页穿搭分析的展示与验证

更新于2026-10-16。采用已确认的流程：3D画廊选中穿搭 → 页面简析 → 主动打开深入分析 → 衣橱应用。

近期内容现采用[每日精选2男装、2女装、1小众风格](daily-trend-selection.md)。该配额不改变以下画廊与深入分析流程；历史分析示例不占当天名额。

## 展示行为

- 点击画廊只更新选中项和下方简析，不立即弹出详情。已有分析展示三个具体要点；未整理深入解读的帖子保留原始摘要、标签与原帖入口，不生成臆测的搭配理由。
- 「深入分析」打开电脑端宽屏、手机端全屏的原生对话框。完整原图与编号对应分析要点，按观察、原因、取舍和验证解释；替换建议明确标为推演。
- 详情打开后暂停画廊轮播。关闭按钮、返回画廊、Escape及电脑端背景点击均可关闭；关闭后恢复入口焦点和原页面位置。Tab和Shift+Tab在详情控件之间循环。
- 「用我的衣橱搭一套」沿用原推荐入口，带入标签与已核验分析的应用方法。详情中的相关衣物按已有标签匹配，仅展示可参与推荐的衣物，不保证版型适配；需要人工确认的衣物排除。

## 穿搭技巧

原单品清单与护理模块现替换为「穿搭技巧」。根据用户纠正，内容已重新检索并核读8篇具体原文，归纳成配色、比例、轮廓、叠穿、风格五个主题，来源及对应关系见[原帖研究记录](research/outfit-techniques-synthesis-2026-10-16.md)。每条先展示署名原帖要点，再给出本帖或跨帖归纳、练习步骤、适用条件和取舍；调整前后示例明确标为编辑推演。参考原帖保留作者、平台、日期、链接与阅读范围。

这批人工整理内容是2026-10-16读取正文后的编辑归纳，原文发布于2016—2021年，不计入每日5套近期穿搭；未查看原图或视频的范围如实标注。现已增加[每周技巧自动整理](weekly-outfit-techniques.md)：从公开来源发现文章、读取正文，归纳与质量复核后每七天最多新增一条；来源或质量不足时保留现有内容。自动技巧明确标注 AI 归纳及未经人工逐条核读，并与原有人工核读内容区分。自查展开及衣橱练习导航继续保留，后者不自动生成或保存。

本次改造的71项前端单元检查、正式构建及35项画廊/深入分析/收藏试穿回归通过。3项技巧交互检查在修正测试重复访问相同地址时的刷新方式后复测通过，包含实际503响应、分类与详情切换、自查重置及衣橱仅导航无写入。已检查1280、390和320像素宽度，未出现页面横向溢出或脚本错误，并验证键盘可收起自查；截图位于`output/outfit-techniques/`。

## 视觉对齐

2026-10-16统一鉴赏页的内容宽度与全站`--page-width`（1240px），保留桌面24px、手机16px的页面外侧留白。试穿入口、简析与技巧详情使用同一组内部留白：桌面24px，手机20px；模块标题、圆角、操作按钮及分隔间距同步统一。

技巧列表与详情在桌面对齐顶部，详情各段沿同一文字边线排列。960px及以下改为横向技巧列表与单列详情；只有一项时卡片铺满可用宽度，手机主题筛选按三列排列，减少不齐的空白。

已查看1440、1280、820、390和320像素宽度的当前截图，逐项核对页面边线、段落留白及手机布局，未出现页面横向溢出或脚本错误。构建与23项技巧、画廊、深入分析及扩展安装入口交互回归通过。截图与几何记录位于`output/visual-alignment/before/`和`after/`；本轮使用只读预览及隔离接口，没有验证真实账户数据或外部试穿服务。

## 内容边界

`frontend/src/data/trendOutfitAnalyses.js`保存当前两篇已核验作品的编辑分析，来源及图片核验范围见[研究记录](research/cross-platform-creator-analysis-sample-2026-10-15.md)。分析只匹配具体原帖链接，不按博主姓名把方法附给其他作品。

「分析示例」使用SavisLook与三木的历史作品，保留原始发布日期和原帖入口，独立于近期趋势筛选、计数与当前选中项。示例图片是已查看原图的本地副本，未做换装或修图。在此模式下收起试穿推广区；从其他入口打开试穿设置时回到近期内容并继续原安装流程。

历史示例没有数据库趋势记录，因此进入推荐时只传递风格与应用方法，不提交不存在的趋势记录ID。此改动没有接入新平台采集，也没有为所有近期帖子增加自动分析服务。
